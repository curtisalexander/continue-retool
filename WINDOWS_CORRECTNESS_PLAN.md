# Windows, shell, and text correctness plan

This is the live implementation checklist for making the MCP toolkit deterministic
across shell dialects, environments, subprocess bytes, files, search, edits, and
model-visible display. Check an item only after its focused tests pass.

## 1. Reproducible development environment

- [x] Add idempotent orb setup and resume scripts.
- [x] Install the CI-pinned `uv`, sync the locked test/dev environment, and install `rg`.
- [x] Run the setup script twice and verify the resume script is fast.

## 2. Shared internal text API

- [x] Add one byte-to-text result type carrying text, encoding, and loss metadata.
- [x] Detect UTF-8 BOM, UTF-16 BOMs, strict UTF-8, cp1252, and latin-1 in a documented order.
- [x] Keep filename decoding separate from file-content decoding.
- [x] Add partition-independent byte-range decoding for a codec selected once per job.
- [x] Add focused shared-helper tests for Unicode, legacy encodings, BOMs, and malformed bytes.

## 3. Shell contract and model consistency

- [x] Expose shell selection as a JSON-schema enum rather than a free-form string.
- [x] Make the model-facing description platform-specific and state the resolved default.
- [x] Reject redundant leading `pwsh`, `powershell`, `bash`, `cmd`, or absolute interpreter invocations with an actionable error.
- [x] Return selected shell, interpreter, and encoding metadata.
- [x] Select one encoding per stdout/stderr stream; remove slice-by-slice guessing and byte trimming.
- [x] Encode interactive input with the job's configured input encoding.
- [x] Define nonzero exit as `ok: false` while preserving output and exit metadata.
- [x] Normalize model-visible display newlines without changing raw captured bytes.
- [x] Build every child environment through one deterministic helper with case-insensitive Windows keys.
- [x] Support explicit variable removal without leaking changes into later jobs.
- [x] Make Windows tree termination asynchronous and bounded.
- [x] Bound post-parent-exit pipe draining so inherited handles cannot hang a job.
- [x] Keep raw overflow recoverable and advertise its required explicit codec.

## 4. Filesystem and editing consistency

- [x] Make `fs.read` use the shared decoder and report encoding/loss metadata.
- [x] Make `edit` use the same decoder and preserve the selected original encoding.
- [x] Detect UTF-16 explicitly and preserve BOM/encoding, rather than misclassifying it as a legacy single-byte file.
- [x] Preserve every original line-ending sequence, including mixed LF/CRLF/CR files.
- [x] Preserve untouched bytes and fail atomically when inserted text is not representable.
- [x] Keep newly created files UTF-8 without BOM and report actual UTF-8 byte counts.

## 5. Search consistency

- [x] Decode ripgrep JSON `text` and base64 `bytes` variants for both content and paths.
- [x] Return character columns separately from ripgrep byte columns.
- [x] Use NUL-delimited file listing so legal filenames are not split on newlines.
- [x] Return structured partial/decode errors rather than allowing parser exceptions to escape.
- [x] Verify legacy file text agrees across search, read, and edit.

## 6. Installer and runtime environment

- [x] Detect and stamp absolute interpreter paths plus the selected default into shell YAML.
- [x] Validate stamped interpreter paths and fall back deterministically.
- [x] Add a safe upgrade path for files previously generated by this installer while preserving user-authored files.
- [x] Make installer doctor launch with the rendered configuration environment, not the terminal's full environment.
- [x] Test minimal GUI-like `PATH` behavior and nonstandard PowerShell locations.
- [x] Keep operator documentation and generated templates synchronized with actual installer behavior.

## 7. End-to-end proof and documentation

- [x] Add real stdio MCP Unicode round trips, not only in-process FastMCP tests.
- [x] Add Windows tests for PowerShell 7, Windows PowerShell, cmd/OEM output, interactive Unicode, and inherited pipe handles.
- [x] Add chunk-partition invariance tests for UTF-8, DBCS OEM codecs, cp1252, and malformed output.
- [x] Add fixtures covering cp1252, UTF-8 BOM, UTF-16, emoji, CJK, combining characters, and mixed line endings across the tool suites.
- [x] Update architecture and tool documentation with the final encoding/environment contracts.
- [x] Run CI lint/type checks, all server and installer tests, metadata/docs checks, and build/package smoke tests available in the orb.
- [x] Confirm the Windows-only tests on the `windows-latest` CI runner.
